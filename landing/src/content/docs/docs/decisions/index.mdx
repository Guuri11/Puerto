The code says *what*. An architecture decision record says *why*: the context, the options that
were weighed, the one that was taken and what it costs. Puerto keeps one for every decision that
is not visible in the code, so that a later session, a person's or an agent's, inherits the
reason instead of re-deriving it or quietly reverting it.

An accepted ADR is never rewritten. When a decision changes, a new ADR supersedes it, and both
link to each other. These pages are the files in
[`docs/adr/`](https://github.com/Guuri11/Puerto/tree/main/docs/adr), published as they are.
