import { adrs } from '@/lib/repo';

El código dice *qué*. Un registro de decisión de arquitectura (ADR) dice *por qué*: el contexto,
las opciones que se sopesaron, la que se tomó y lo que cuesta. Puerto guarda uno por cada decisión
que no se ve en el código, para que una sesión posterior, de una persona o de un agente, herede el
motivo en lugar de volver a deducirlo o de deshacerlo sin darse cuenta.

Una ADR aceptada no se reescribe. Cuando una decisión cambia, otra ADR la sustituye, y las dos se
enlazan. Estas páginas son los ficheros de
[`docs/adr/`](https://github.com/Guuri11/Puerto/tree/main/docs/adr), publicados tal cual: en
inglés hasta la 0022, y en castellano desde la 0023, como el código que genera Puerto.

## Por dónde empezar

- [0023: Un crate por contexto y capa](/docs/decisions/adr/0023-crates-por-contexto-y-capa/) es la
  estructura de un proyecto generado, con las medidas que la respaldan.
- [0024: Todo lo generado en castellano](/docs/decisions/adr/0024-lo-generado-en-castellano/) es
  la regla del idioma y sus excepciones; el vocabulario está en el
  [glosario](https://github.com/Guuri11/Puerto/blob/main/docs/glosario.md).
- [0017: Los crates del runtime junto al generador](/docs/decisions/adr/0017-runtime-crates-next-to-the-generator/)
  traza la línea entre lo que Puerto genera y lo que publica como dependencia, y lo compara con
  Loco, Pavex, Laravel, Rails y Spring Boot.
- [0018: Eventos de dominio](/docs/decisions/adr/0018-domain-events-outbox-pluggable-transport/) es
  el outbox, la unidad de trabajo y el worker.
- [0021: Auth](/docs/decisions/adr/0021-auth-one-authenticator-port-oidc-or-local/) es un puerto
  con dos adaptadores, OIDC o sesiones locales.
- [0010: Las reglas para agentes tienen tests](/docs/decisions/adr/0010-generated-agent-rules-are-tested/)
  es por qué `AGENTS.md` no se puede desfasar.
- [0025: El frontend es presentación](/docs/decisions/adr/0025-el-frontend-es-presentacion/) es por
  qué `web/` no tiene dominio, casos de uso ni adaptadores propios.
