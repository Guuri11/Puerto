## La CLI

```bash
cargo install puerto --locked
puerto --version
```

`--locked` compila con las versiones de dependencias con las que se probó Puerto. Compilar Puerto
pide Rust 1.85 o posterior. Los proyectos que genera fijan su propia toolchain (mira más abajo),
así que [rustup](https://rustup.rs) es la forma recomendada de tener Rust.

El autocompletado de la shell es un comando:

```bash
puerto completions zsh > ~/.zfunc/_puerto     # bash, elvish, fish, powershell, zsh
```

## Lo que usa un proyecto generado

Puerto solo escribe ficheros. Arrancar el proyecto pide las herramientas de siempre, y su
`Makefile` instala las de Rust:

```bash
make setup    # cargo-nextest, cargo-audit, y sqlx-cli en los proyectos --db
```

| Herramienta | Cuándo | Para qué |
|---|---|---|
| [rustup](https://rustup.rs) | siempre | El `rust-toolchain.toml` del proyecto fija Rust 1.95.0 con `rustfmt` y `clippy`, así que `make lint` responde lo mismo en todas las máquinas ([ADR-0009](/docs/decisions/adr/0009-generated-projects-pin-their-toolchain/)) |
| [cargo-nextest](https://nexte.st) | siempre | `make test` ejecuta el workspace con él |
| Docker | `--db`, `--eventos`, `--auth oidc`, `generar correo` | `docker-compose.yml` arranca Postgres, Mailpit, Keycloak o Redpanda para desarrollo |
| [sqlx-cli](https://github.com/launchbadge/sqlx/tree/main/sqlx-cli) | `--db` | `make sqlx/migrate` y `make sqlx/prepare` |
| [Bun](https://bun.sh) | el frontend web (por defecto) | `web/` es React sobre Bun. `--sin-web` lo quita |
| `cmake`, cabeceras de libcurl | `--eventos kafka` | `rdkafka` compila librdkafka desde el código fuente |

<Aside type="note">
Para un proyecto Kafka, las cabeceras de libcurl son `libcurl4-openssl-dev` en Debian y Ubuntu y
`curl` en Arch, y vienen con Xcode en macOS.
</Aside>

## Actualizar

```bash
cargo install puerto --locked --force
```

Un proyecto depende de los crates del runtime de la minor que lo generó. Cuando actualices la CLI,
lee [Actualizar](/docs/guides/upgrading/): `puerto validar` avisa cuando las dos se separan.
